# 私のウェブサイト

このリポジトリは、GitHub Pagesでホスティングされている私の個人ウェブサイトです。

## 構成

- `index.html` - メインページ
- `styles.css` - スタイルシート

## ローカルでの実行方法

1. リポジトリをクローンします：
```bash
git clone [リポジトリのURL]
```

2. `index.html`をブラウザで開きます。

## GitHub Pagesでの公開方法

1. GitHubリポジトリの設定（Settings）に移動
2. 左サイドバーの「Pages」を選択
3. 「Source」セクションで「main」ブランチを選択
4. 「Save」をクリック

これで、`https://[ユーザー名].github.io/[リポジトリ名]`でサイトにアクセスできるようになります。
